# Spam and Phishing Email Detection

This AIOps project classifies email text as legitimate or suspicious. IT teams can use the result to decide which emails to flag for review. We compare multinomial Naive Bayes and logistic regression and record both runs in MLflow.

## Dataset

`src/train.py` reads `data/phishing_email.csv`. The `text_combined` column contains the email text, and `label` contains the class. On another PC, place the same CSV at `data/phishing_email.csv` before running the project. [Kaggle dataset](https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset) · [Dataset DOI](https://doi.org/10.34740/kaggle/ds/5074342) · [CC BY-SA 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/)

| Label | Meaning | Original rows |
| --- | --- | ---: |
| `0` | Legitimate email | 39,595 |
| `1` | Spam or phishing | 42,891 |
| **Total** | | **82,486** |

The script normalizes whitespace and letter case, removes rows with empty text or labels, and removes exact duplicates. If the same text has conflicting labels, it removes all copies. The cleaned data is split into 80% training and 20% test data, stratified by label with seed `42`.

## Windows setup

Use Python 3.12 and run the commands from the project folder in PowerShell.

### First setup on a PC

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Open a new terminal

Activate the existing environment in each new PowerShell window.

```powershell
.\.venv\Scripts\Activate.ps1
```

## Check the dataset and split

Use this command as a quick check after setup.

```powershell
python src/train.py --split-only
```

The terminal should show **82,077 emails after cleaning**, with **65,661 for training** and **16,416 for testing**.

To see the available options, run this command.

```powershell
python src/train.py --help
```

## Train the models

Before training, set the location of the local MLflow database in the current PowerShell window.

```powershell
$env:MLFLOW_TRACKING_URI = "sqlite:///mlflow.db"
```

### Compare both models

```powershell
python src/train.py
```

This trains and evaluates Naive Bayes and logistic regression on the same split. It writes `results/metrics.csv` and creates two MLflow runs.

To display the comparison CSV in PowerShell, run this command.

```powershell
Import-Csv .\results\metrics.csv | Format-Table -AutoSize
```

### Train Naive Bayes only

```powershell
python src/train.py --baseline-only
```

This evaluates the baseline, writes `results/baseline_metrics.csv`, and creates one MLflow run.

To display the baseline CSV in PowerShell, run this command.

```powershell
Import-Csv .\results\baseline_metrics.csv | Format-Table -AutoSize
```

## View the runs in MLflow

Open PowerShell in the project folder with `.venv` active. Use this command after training or to reopen runs already saved in `mlflow.db`.

```powershell
mlflow server --backend-store-uri "sqlite:///mlflow.db" --host 127.0.0.1 --port 5000
```

Keep the terminal open. In the browser, select **Spam and Phishing Email Detection** and click **Training runs**. After a full comparison, look for **Naive Bayes (baseline)** and **Logistic regression**. [Open local MLflow](http://127.0.0.1:5000)

Open a run to see its parameters and metrics. Under **Artifacts**, open `confusion_matrix.json` to see the classification counts. The **Models** column links to the trained pipeline. Press **Ctrl+C** in PowerShell to stop the server.

## Model comparison

Both models use TF-IDF with `min_df=2` and `max_features=30000`. Each pipeline learns its vocabulary and word weights from the training emails. Multinomial Naive Bayes is the baseline. Logistic regression uses `solver="liblinear"`, `max_iter=1000`, and `random_state=42`.

**Recall** is our main metric. It measures the share of spam or phishing emails the model catches. **Precision** measures the share of flagged emails that really were spam or phishing. **F1** combines precision and recall.

| Model | Precision | Recall | F1 | Legitimate emails flagged by mistake | Spam or phishing emails missed |
| --- | ---: | ---: | ---: | ---: | ---: |
| Multinomial Naive Bayes | 98.41% | 96.81% | 97.61% | 134 | 273 |
| Logistic regression | 98.29% | 99.02% | 98.65% | 148 | 84 |

On the same test set, logistic regression missed **189 fewer** spam or phishing emails and flagged **14 more** legitimate emails for review.

These results come from one split of a public dataset. Similar email templates can appear in both sets after exact duplicate removal. A company inbox can contain a different mix of emails.
